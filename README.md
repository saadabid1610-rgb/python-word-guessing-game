# Python Word Guessing Game 🎯

This is a word guessing game I made using Python. The player can select a difficulty level and then tries to guess the randomly selected word.

## What It Does

* Has three difficulty levels: Easy, Normal, and Hard
* Selects a random word from the selected level
* Counts the number of attempts
* Gives a hint after an incorrect guess
* Continues until the correct word is guessed

## What I Used

* Python
* `random` module
* Lists
* `random.choice()`
* `while` loops
* `for` loops
* `if`, `elif`, and `else`
* String indexing
* User input

## How to Run

Make sure Python is installed on your computer.

Open the project folder in the terminal and run:

```bash
python word_guessing.py
```
